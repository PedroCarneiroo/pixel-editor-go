## 🎨 Pixel Art Editor em Go

Este é um editor interativo que desenvolvi para explorar a criação de interfaces gráficas e a interação do usuário usando Go. Ele permite desenhar e visualizar criações diretamente em uma janela renderizada pelo código.

### 🎯 Meu Aprendizado e Experiência
Como estudante focado em desenvolvimento de software, construí este projeto para ir além do terminal de texto e entender na prática como funcionam as aplicações visuais. Os principais conceitos que apliquei foram:

* **Lógica de Tela (Game Loop):** Como uma interface é desenhada e atualizada continuamente para se manter responsiva.
* **Eventos de Input:** Captura de cliques do mouse e conversão matemática para preencher o grid na tela.
* **Estrutura de Dados:** Utilização de matrizes (arrays bidimensionais) para salvar a cor de cada pixel na memória do programa.
* **Pacotes Externos:** Uso do gerenciador `go mod` para integrar bibliotecas de terceiros ao código.

### 🛠️ Tecnologias e Ferramentas
* **Linguagem:** Go (Golang)
* **Biblioteca Gráfica:** Ebitengine 
* **Versionamento:** Git e GitHub
